## Interview Perspective

### Common Interview Questions

**Q1: What is Playwright?**  
Playwright is a modern end-to-end automation framework developed by Microsoft that supports fast, reliable, and cross-browser testing with built-in auto-waits and parallel execution.

**Q2: Why would you choose Playwright over Selenium?**  
Playwright offers better stability, faster execution, built-in synchronization, native cross-browser support, and excellent handling of modern web applications, which reduces test flakiness in CI pipelines.

**Q3: Which browsers does Playwright support?**  
Playwright supports Chromium, Firefox, and WebKit.

---

## Key Takeaways

- Playwright is built for modern web automation
- It reduces flakiness through auto-waiting
- It enables fast and scalable test execution
- Understanding *why* Playwright exists is as important as knowing *how* to use it
